This repository contains a step-by-step guide to download and restore Microsoft's **AdventureWorks2022** sample database into **SQL Server Management Studio (SSMS)**.

## 🛠️ Requirements

- [SQL Server Management Studio (SSMS)](https://learn.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms) — free download from Microsoft
- An active SQL Server instance on your computer

---

## 🗄️ About the database

**AdventureWorks2022** is Microsoft's official sample database. It simulates a fictional manufacturing company and contains data across sales, human resources, production, and purchasing.

It is widely used for learning and practising SQL Server.

- [Official Microsoft page for AdventureWorks sample databases](https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure?view=sql-server-ver16&tabs=ssms)
